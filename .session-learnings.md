# Session Learnings: v1.0.0 → v1.1.0.0

Date: 2026-05-05
Session: windows-residual-cleaner interactive confirmation feature

## Critical Bugs Found & Fixed

### 1. Set-Id [ref] Counter Trap (ID Duplication)
- **Symptom**: 520 items, only 6 unique IDs
- **Root cause**: `[ref]$counters.fs` in `[CmdletBinding]` function points to temporary copy; increments never reflect back
- **Fix**: Direct hashtable mutation `$counters[$key]++`
- **Confidence**: 10/10

### 2. scan-uninstalled 100% False Positive
- **Symptom**: All 72 "uninstalled" entries were actually installed software
- **Root cause**: Three signals OR-ed independently; index membership (authoritative) was overridden by path-missing/uninstall-missing
- **Fix**: AND logic — require NOT in index AND (path missing OR uninstall string missing); skip MsiExec entries
- **Confidence**: 10/10

### 3. Ghost Tasks False Positives
- **Symptom**: 56 ghost tasks, all false positives
- **Root cause**: `%windir%` not expanded, quotes not stripped, bare exe names treated as missing paths
- **Fix**: `ExpandEnvironmentVariables()` + `.Trim('"')` + skip bare exe names
- **Confidence**: 10/10

### 4. PS 5.1 Variable Type Constraint Conflict
- **Symptom**: `clean-residuals.ps1` matched 0 items with ConfirmFile
- **Root cause**: `[string]$ItemsToClean` parameter constrains ALL case-insensitive variants; `$itemsToClean += $item` does string concatenation
- **Fix**: Rename working variable to `$cleanupItems`
- **Confidence**: 9/10

### 5. Where-Object Single-Item .Count
- **Symptom**: Summary shows "4 succeeded" for 1 processed item
- **Root cause**: Single-item `Where-Object` result is a Hashtable, `.Count` returns key count (4) not element count (1)
- **Fix**: `@($filtered).Count`
- **Confidence**: 9/10

## Reusable Patterns

### Multi-Criteria Detection Logic
```
Authoritative signal (index membership) MUST gate supplementary signals.
Wrong:  if (A OR B OR C) → flag
Right: if (NOT A AND (B OR C)) → flag
```

### Four-Tier File Deletion Fallback
```powershell
1. Remove-Item -Recurse -Force
2. takeown.exe /f /r + icacls.exe /grant Administrators:F /T
3. cmd /c "rd /s /q \"$path\""
4. Rename to ~filename.deleted + MoveFileEx (deferred delete on reboot)
```

### Registry Path Sanitization
```powershell
$path = $registryValue.Trim('"')
$path = [Environment]::ExpandEnvironmentVariables($path)
if ($path -match '^[A-Z]:\\') { Test-Path $path }
```

## PowerShell Pitfalls for AGENTS.md

- `[ref]` + `[CmdletBinding]` = broken by-value semantics for value types
- `[string]$Param` constrains ALL case-insensitive variants of that variable name
- `Where-Object` single-item result `.Count` = property count, not element count
- `.NET IO methods` treat quotes as literal path characters
- `$PSScriptRoot` relative paths must be standardized across all scripts

## Integration Test Lessons

- Mock tests passed for all 3 bugs above — mocks hid the real issues
- Real-environment testing is mandatory for Windows registry/filesystem/service interactions
- Minimum integration test: call the REAL function once and verify invariants
